# AI Development Log

## 1. Purpose

This document records the use of AI tools during the development of CRAM MART. It documents how AI assistance was used for planning, coding, debugging, UI design, documentation, and evaluation while keeping the development decisions and final implementation under the team's control.

## 2. AI-Assisted Development Process

### 2.1 Planning and System Design
- Used AI to brainstorm the CRAM MART concept and kiosk workflow.
- Used AI to organize system features and requirements.
- Used AI to suggest a suitable technology stack.
- The team reviewed and selected the final suggestions based on project requirements and feasibility.

### 2.2 Code Generation
- Used AI-assisted coding to generate and improve React, JavaScript, CSS, and Supabase-related code.
- AI suggestions were reviewed and modified before being incorporated into the project.
- The team tested generated code to ensure that it worked with the existing application.

### 2.3 Debugging
AI assistance was used to:
- Interpret error messages.
- Identify possible causes of bugs.
- Suggest debugging steps.
- Improve database queries.
- Resolve frontend and backend integration issues.

### 2.4 UI/UX Improvement
AI was used to suggest:
- Kiosk-friendly layouts.
- Color palettes.
- Product card designs.
- Cart layouts.
- Touchscreen-friendly controls.
- Responsive design improvements.

The team evaluated the suggestions and selected designs that fit the CRAM MART theme and project requirements.

### 2.5 Documentation
AI assistance was used to:
- Organize the README.
- Improve technical explanations.
- Structure project documentation.
- Review wording and formatting.

AI-generated suggestions were not automatically accepted. The team reviewed, tested, modified, and integrated the suggestions according to the actual requirements of the CRAM MART system.

The final implementation reflects the team's decisions, testing, and modifications.
