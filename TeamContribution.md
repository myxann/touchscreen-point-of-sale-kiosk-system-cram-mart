## 3. GitHub Workflow

The team used feature branches to separate development tasks from the main branch.

Typical workflow:

1. Create or switch to a feature branch.
2. Develop and test the assigned feature.
3. Commit the changes with a descriptive commit message.
4. Push the branch to GitHub.
5. Create a pull request.
6. Review the changes.
7. Address required revisions.
8. Merge the approved changes into the main branch.
